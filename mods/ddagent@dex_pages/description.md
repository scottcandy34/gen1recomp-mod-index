Adds extra pages to the Pokédex without changing the original entry screen.

New information available:
- Type matchups
- Catch rate / odds
- Encounter locations
- Level-up move list
- TM/HM compatibility
- Evolution methods

Everything is presented in the same visual style as the vanilla Pokédex.
