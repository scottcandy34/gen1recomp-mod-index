Three related systems behind toggles:

1. **Dynamic level caps** based on badges owned
2. **Break the level 100 limit** (optional)
3. **Candy jar** — while level caps are active, excess EXP that would have overflowed is stored in a jar (appears above Save) so you can redistribute it later instead of auto-leveling past the cap

Initial release with post-load bug fixes in 1.0.1.
