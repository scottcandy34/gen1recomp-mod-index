Repurposes the Player PC to act as a TM Case like later generations (50-slot max).

Features:
- Dedicated TM/HM pouch separate from the regular bag
- Works with the Dual Bags mod
- Toggle for Modern UI compatibility (ArmstrongThomas gen1-modern-ui)
- TM/HM summary screen
- Party learn menu no longer kicks you out of the pouch
- Cursor remembers last position
